# macOS 28 베타 확인 체크리스트

macOS 28 베타(예상: 2027-06 WWDC)가 나오면 그날 바로 돌려 보는 목록입니다. 배경은 [macOS 28 대응 계획](macOS28-대응계획.md)에 있습니다.

> ⚠️ 베타는 **실사용 맥이 아니라 별도 볼륨이나 테스트용 맥**에 설치하세요. 세이브(`~/Library/Application Support/삼국지6/Game/SAVEDA*.S6`)는 미리 백업해 두세요.

## 1단계 — 자동 점검 (5분)

터미널에서 레포의 점검 스크립트를 실행합니다. 더블클릭해도 됩니다.

```bash
./scripts/macos28-check.command
```

설치·sudo·prefix 수정은 하지 않습니다. 결과는 바탕화면에 `삼국지6-macos28-check-<날짜>.txt` 로 저장됩니다.

| # | 확인 항목 | 통과 기준 | 실패 시 의미 |
|---|---|---|---|
| 1 | 환경 | `ProductVersion` 28.x, `arm64` | — |
| 2 | Rosetta 패키지·데몬 (참고용) | `oahd` 가 있고 실행 중 | Rosetta 자체가 빠졌거나 축소됨 |
| 3 | 일반 x86_64 실행 `arch -x86_64 /usr/bin/true` | PASS | 시스템 바이너리의 x86_64 부분이 빠졌을 수도 있으니 **이것만으로 판정하지 않음** |
| 4 | `softwareupdate --install-rosetta` 옵션 존재 | 옵션이 보임 | 재설치 경로가 없어짐 |
| 5 | **Wine 엔진 `wine --version`** | `wine-11.0` 출력 | `Bad CPU type` 이면 Wine 이 "게임용 Rosetta" 대상이 아님 → **(d) 실패** |
| 6 | **임시 prefix 에서 `wine cmd /c echo`** | `SAM6_OK` 출력 | 엔진은 실행되지만 기동 중에 막힘 (oahd 로그 확인) |
| 7 | oahd/rosetta 로그 (참고용) | — | 거부·미지원 문구가 있으면 기록 |

- **5·6 이 PASS 면** 2단계로 가서 게임을 실제로 켜 봅니다.
- **5·6 이 FAIL 이면** 지금 방식은 macOS 28 에서 끝난 것입니다. 3단계 ARM64 엔진 확인으로 넘어갑니다.

## 2단계 — 지금 Wine 경로로 게임 확인 (5·6 PASS 일 때)

바탕화면 `삼국지6` 아이콘으로 실행합니다.

- [ ] 게임 창이 뜸 (CD-ROM 창 → 취소, "화면 재생 실패" → 확인)
- [ ] 메뉴바(파일·편집·정보…)와 툴바 버튼의 한글이 정상
- [ ] 초기설정 대화상자 한글이 정상
- [ ] 데이터 로드 → 맵에서 **툴바 군주 이름이 한글**로 나옴 ("III" 이나 □ 이 아님)
- [ ] 대사·도시 이름 한글 정상
- [ ] **전투 화면(특히 수전)을 10분 이상 진행해도 멈추지 않음** (전술 시뮬레이션 → 적벽 전투가 빠름)
- [ ] 효과음 재생
- [ ] 저장 → 종료 → 다시 실행 → 로드 정상
- [ ] 설치 도구(`설치.command`)를 새 사용자 계정이나 테스트용 HOME 에서 처음부터 실행해도 끝까지 성공

## 3단계 — ARM64 엔진 확인 (Rosetta 없이)

macOS 28 에서 지금 경로가 살아남더라도 함께 확인합니다. 그다음 해(macOS 29)를 대비하기 위해서입니다.

- [ ] **Rosetta 가 없는 상태**인지 확인 (`arch -x86_64 /usr/bin/true` 가 실패해야 의미 있는 테스트)
- [ ] 후보 엔진 설치: Mach9 (macOS 27 에서 검증한 `arm64-11.20-5` 부터) / CrossOver 27 arm64
- [ ] 새 win64 prefix 생성 → AppleGothic 복사 + `assets/reg/*.reg` 적용 → [엔진 독립 폰트 픽스](macOS28-대응계획.md#4-프로토타입--엔진-독립-한글-폰트-픽스) 적용
- [ ] `LANG=ko_KR.UTF-8 LC_ALL=ko_KR.UTF-8` 로 SAM6.EXE 실행 (CrossOver 는 bottle 설정 `LC_ALL`)
- [ ] 2단계의 한글·전투·사운드·세이브 항목을 똑같이 확인
- [ ] `Activity Monitor` 의 "종류" 열이 `Apple` 인지 확인 (`Intel` 이면 Rosetta 로 돌고 있는 것)
- [ ] `/usr/lib/libRosetta.dylib`·`liboah.dylib` 가 사라져도 엔진이 뜨는지 (Mach9 프로세스가 이 둘을 매핑함. `vmmap <pid> | grep -i -E "rosetta|oah"`)
- [ ] 프리징 판단: 맵에서 입력을 기다릴 때도 CPU 가 약 100% 인 건 이 게임의 정상 동작입니다(Rosetta 엔진도 같음). **화면이 한 프레임에서 멈추고 클릭에 반응하지 않으면** 프리징
